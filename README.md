단일 HTML 파일로 구성되어 있으며 별도 빌드 과정이 없습니다.

**공개 주소:** https://jeffkim2021.github.io/ibc2026-report/

## 자료 구분

보고서 본문은 출처를 색으로 구분합니다.

- **파란색 블록** — 내부 출장 기록 (직접 확인·기록한 내용)
- **황색 블록** — 외부 공개 자료 (주최 측·업계 매체·업체 발표, 블록마다 개별 출처 명기)
- **점선 박스** — 내부 자료 미확보 구간

## 보완 필요 항목

- 폐막일(4일차) 시간대별 부스 운영 및 철수 내역
- 최종 방문객 리드 집계
- 자사 부스 전시 Zone 구성 및 데모 항목
- LG유플러스 협업 전시 운영 내역
- STRONG·KT 현장 촬영 사진 (공개 자료 미확인 업체)

## 이미지 관련

수록 사진은 IBC 공식 자료와 IBC365 기사 이미지를 원 서버에서 직접 참조합니다.
저작권은 각 출처에 있으며, 링크가 만료되면 해당 사진 영역은 자동으로 숨겨집니다.
사내 배포용으로 이미지를 고정하려면 파일을 내려받아 `assets/` 폴더에 넣고
`index.html`의 해당 `src` 경로를 수정하십시오.
